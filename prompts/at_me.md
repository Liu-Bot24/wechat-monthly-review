## 本次任务：说明每一条 @我 的消息是什么事

下面用户消息中有若干段聊天，每段围绕一条 @我 的消息（标为【@我】），前后附有上下文。每行开头的 `m数字` 是消息编号。

对每一条【@我】消息写一项，一条都不能漏，也不要为其他消息写。只输出一个 JSON 对象：

```json
{
  "items": [
    {"msg_id": "m123", "who": "谁 @ 了我", "what": "什么事，一句话", "ask": "需要我做什么；不需要就写 无", "importance": 3}
  ]
}
```

`importance`：5 = 必须尽快处理，4 = 要处理，3 = 知道就行，2 = 顺带提到，1 = 无关紧要（例如群发、玩笑）。
