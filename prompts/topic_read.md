## 本次任务：按专题要求精读一段聊天，写结论卡

这次不是月报，而是一次单独的专题总结。本提示最后写着这次的专题要求：时间、话题和侧重。准则第 1 节说的"这个月"，这次指所选的时间；一条内容值不值得写，以专题要求为准：

- 指定了话题时，只写和这个话题有关的内容。和话题无关的聊天，即使对我很重要也不写。
- 没有指定话题时，写这些会话在这段时间里值得留下的内容：发生了什么、谈定了什么、谁答应了什么、还有什么没办完。不只写和我有关的部分，别人之间的重要讨论也写，写清是谁和谁。
- 侧重里写到的方面优先，写得更细。

下面用户消息中是一个会话的聊天记录（经过压缩和遮蔽，`⟦…⟧` 是代码替换掉的账号、密码、密钥等，方括号里写明了原来是什么）。每行开头的 `m数字` 是消息编号，`↪m数字` 表示这条在回复那条消息。会话可能只截取了和专题有关的片段，片段之间省略了无关的聊天，不要猜省略的部分。标为"上下文"的日期不在所选时间内，只用来理解，不为它单独出卡。

只输出一个 JSON 对象：

```json
{
  "chat_note": "一句话：这个会话在所选时间里和专题有关的情况（可以为空字符串）",
  "cards": [
    {
      "kind": "事件|决定|承诺|待办|信息|资源|观点|关系变化|人生事件|风险|自我记录",
      "title": "不超过 20 字",
      "summary": "不超过 120 字，写结论",
      "who": ["相关的人"],
      "when": "YYYY-MM-DD",
      "msg_ids": ["m123"],
      "importance": 1,
      "confidence": "高|中|低",
      "why_for_me": "一句话：和专题的关系",
      "action": "无|回复|备忘|看图|看视频|听语音|核实|跟进",
      "open_loop": false,
      "sensitivity": "正常|仅定位",
      "sensitive_category": "仅定位时填写类别；否则为空",
      "why_look": "仅定位时用一句话写为什么可能需要看，不复述内容，也不写会话、日期和编号；否则为空"
    }
  ]
}
```

- `msg_ids` 只能用本段中出现、并且在所选时间内的编号。
- `importance` 按和专题的关系打分：5 = 专题的核心内容，4 = 重要，3 = 值得一提，2 = 背景，1 = 可以省略。
- 结论卡照常称我为"你"，别人写名字或称呼；成稿时会按要求的视角改写人称。
- `sensitivity` 为"仅定位"时，`title` 和 `summary` 写成空字符串。
- 这一段没有和专题有关的内容时，`cards` 为空数组。
