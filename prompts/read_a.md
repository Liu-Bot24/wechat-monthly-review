## 本次任务：精读一段与我直接相关的聊天，写结论卡

下面用户消息中是一个会话的一段聊天记录（经过压缩和遮蔽，`⟦…⟧` 是代码替换掉的账号、密码、密钥等，方括号里写明了原来是什么）。每行开头的 `m数字` 是消息编号，`↪m数字` 表示这条在回复那条消息。标为"上下文"的日期段不在本月，只用来理解，不为它单独出卡。

只输出一个 JSON 对象：

```json
{
  "chat_note": "一句话：这个人或这个群本月和我的关系、情况（可以为空字符串）",
  "cards": [
    {
      "kind": "事件|决定|承诺|待办|信息|资源|观点|关系变化|人生事件|风险|自我记录",
      "title": "不超过 20 字",
      "summary": "不超过 80 字，写结论",
      "who": ["相关的人"],
      "when": "YYYY-MM-DD",
      "msg_ids": ["m123"],
      "importance": 1,
      "confidence": "高|中|低",
      "why_for_me": "一句话",
      "action": "无|回复|备忘|看图|看视频|听语音|核实|跟进",
      "open_loop": false,
      "sensitivity": "正常|仅定位",
      "sensitive_category": "仅定位时填写类别，例如 第三方健康、私密内容、法律纠纷；否则为空",
      "why_look": "仅定位时用一句话写为什么我可能需要看，不复述内容，也不写会话、日期和编号；否则为空"
    }
  ],
  "images": [
    {
      "msg_id": "m130",
      "for_card": 0,
      "privacy": "正常|证件|银行卡|密码或验证码|私密照片|他人病历|其他隐私",
      "question": "privacy 为正常时：要从图里确认什么，一句话；否则为空",
      "note": "一句话：这张图在对话里起什么作用，例如 租房登记时发送的证件；不写图里的内容"
    }
  ]
}
```

- `msg_ids` 只能用本段中出现、并且属于本月的编号。
- `sensitivity` 为"仅定位"时，`title` 和 `summary` 写成空字符串，内容不进报告。
- `images` 按准则中"图片"一条判断：只为看了能改变或补全结论的图申请；隐私类的图只标类别，不申请看内容。`msg_id` 必须是本段中的图片消息。`for_card` 是这张图对应的 `cards` 下标，不对应任何卡就写 -1。视频和语音不要放进来。
- 没有值得写的内容时，`cards` 和 `images` 为空数组。
