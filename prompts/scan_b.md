## 本次任务：扫读一段我没有参与的群聊

下面用户消息中是一个群的一段聊天记录（经过压缩和遮蔽，`⟦…⟧` 是代码替换掉的账号、密码、密钥等）。每行开头的 `m数字` 是消息编号，`‹域名›` 是链接所在的网站。我和这些对话没有直接关系，你要找出其中值得我知道的内容。这一块不长，请逐条看完，不要只看开头。

只输出一个 JSON 对象：

```json
{
  "note": "一句话概括这一块在聊什么；没有值得说的就写空字符串",
  "topics": [
    {"title": "不超过 20 字", "summary": "不超过 100 字，写有用的结论或信息", "msg_ids": ["m123"], "value": 3}
  ],
  "links": [
    {"title": "链接标题", "why": "为什么值得读", "msg_id": "m123"}
  ],
  "images": [
    {"msg_id": "m130", "for_topic": 0, "privacy": "正常|证件|银行卡|密码或验证码|私密照片|他人病历|其他隐私",
     "question": "privacy 为正常时：要从图里确认什么；否则为空", "note": "一句话：这张图在对话里起什么作用"}
  ],
  "escalations": [
    {"msg_ids": ["m123"], "reason": "为什么需要精读"}
  ]
}
```

- `value`：5 = 必须告诉我，4 = 很有用，3 = 值得一提，2 及以下不要写。
- `images` 只为 value 4 以上的话题申请，并且图里的内容是这个话题的关键（例如截图里的价格、规则、教程步骤）。`for_topic` 是对应的 `topics` 下标。
- 四个数组都可以为空，这是正常结果。
