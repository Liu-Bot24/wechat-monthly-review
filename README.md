# 消息月报（ChatMonthly）

把微信聊天记录归档按月整理成一份月报：这个月发生了什么、有哪些事需要你处理、哪些地方值得点开原文看。可以生成任意一个已经结束的月份，也可以一个月一个月往回补。另有"专题"：用一句话说想总结什么（某件事、某个人、某段时间），整理成一份单独的总结。

阅读和写作由你配置的大模型接口完成；其中的文字环节也可以交给你自己的 AI Agent 去做（见下方"外部 Agent"）。本仓库只有程序，不含任何聊天内容和月报。

## 下载与安装

需要 64 位 Windows 10/11，以及 WebView2（Windows 11 自带，Windows 10 一般已随 Edge 装好）。不需要安装 Python。

在 [Releases](https://github.com/Liu-Bot24/wechat-monthly-review/releases) 下载其中一种，两种的用户数据相同，可以互换：

- **安装版** `ChatMonthly-<版本>-Setup.exe`：不需要管理员权限，默认装到 `%LOCALAPPDATA%\Programs\ChatMonthly\`，在开始菜单和桌面放"消息月报"（桌面图标可以在安装时取消）。升级时运行新版本的安装程序即可；卸载在 设置 › 应用 › 已安装的应用 中进行。
- **绿色版** `ChatMonthly-<版本>-Portable.zip`：解压到任意文件夹，运行其中的 `ChatMonthly.exe`。设置都在程序旁边的 `配置\` 文件夹里，整个文件夹可以直接拷走。升级时先关闭窗口，用新版本的 `ChatMonthly.exe`、`mr.exe` 和 `_internal\` 替换旧的，保留 `配置\`。

升级、重装和卸载都不动你的设置和月报。

## 第一次使用

1. 设置 › 常规：选择归档目录（格式见下方"归档的格式"）和月报的输出目录。
2. 设置 › 接口与模型：添加接口（任何兼容 OpenAI Responses 或 Chat Completions 的服务都可以，本机或在线），填入密钥；添加模型；在"环节分配"里给每个环节选一个模型。可以先点"测试"确认接口和模型能用。
3. 没有语音转写接口或能看图的模型时，在同一页把"语音转写""看图"这两个环节关掉。还有开着的环节没选模型时，生成不会开始，并列出是哪些环节。
4. 总览：选月份，先"估算"（不调用模型，看会读多少、大约用多少 token），再"生成"。

在新电脑或新账户上：在原来的窗口中 设置 › 配置文件 › 导出，得到一个 `.zip`，在新的窗口中导入。密钥不在导出的文件里：同一个 Windows 账户里可以直接用；换了电脑或账户，要在 设置 › 接口与模型 中重新填一次。

## 页面

| 页面 | 用途 |
| --- | --- |
| 总览 | 各月份的状态（未生成、完成、部分失败、预算暂停、等待外部 Agent……）；可以多选月份，一次估算或排队生成 |
| 月报 | 阅读月报；点 `[#编号]` 在旁边显示原始聊天上下文（含图片、语音、视频、文件），勾选行动项会写回月报。"读取范围"在这里：选择哪些会话不读，支持按分类整组、搜索、拼音、多选和撤销 |
| 专题 | 用一句话描述想总结什么，模型拆成时间、范围、话题和写法，你改好后估算、生成 |
| 任务 | 当前任务的进度、预计剩余时间和 token；排队、停止、继续、运行记录和日志 |
| 语音 | 单独批量转写语音，查看结果和失败项 |
| 用量 | 每期月报和每个专题实际用了多少：按环节、模型统计 token、调用次数和费用（填了单价时） |
| 设置 | 接口与模型、环节分配、外部 Agent；归档和输出位置、预算、并发；高级参数；配置导入导出；诊断 |

## 隐私

- 读取范围内的聊天内容会发给你配置的接口；不读的会话在取数时就丢弃，不会发出去。
- 发送之前，代码先把密码、验证码、密钥和令牌、身份证号、银行卡号等替换成 `⟦类型·编号⟧`，模型看不到原值。
- 图片只发送阅读时申请看的那些；按上下文判断为证件、银行卡、私密照片等的图片不发送，月报里只给位置。
- 密钥不写进任何文件，在界面中输入后存进 Windows 凭据管理器。
- 月报、缓存和读取范围（含联系人名字）都在你自己的电脑上，不要放进公开的仓库或分享出去。

## 归档的格式

程序只读归档目录里的 Markdown 文档，不依赖生成它的工具，也不要求固定的文件夹名或文件名。归档是这样的就能用：

- 每个会话一个文件夹，聊天记录文档在它下面的一层子文件夹里，按月份分开（一个月可以有多个文档）。会话文件夹上面的各层文件夹是它的分类；文件夹名开头用来排序的数字和下划线（例如 `05_`）在显示时去掉。
- 每个文档以这几行开头：

  ```
  # 会话名 · 2026-10
  会话：<会话 ID>
  我：<我自己的 ID>
  群人数：<人数>
  ```

  `群人数` 只有群聊有，可以省略。会话 ID 以 `@chatroom` 结尾的也按群聊处理。
- 每条消息是这样一段：

  ```
  <a id="msg-…"></a>
  ### 2026-10-01 09:30:00 · 发送者显示名 · 消息类型

  发送者：<发送者 ID> · 引用：<被引用消息的 msg-…> · 提到：<ID,ID>

  > 正文，每行以 "> " 开头

  - [附件名](附件相对于这个文档的路径)
  ```

  `引用`、`提到` 没有时省略；`提到` 里有"我"的 ID 就是 @我。时间按北京时间（UTC+8）。正文是转义过的 Markdown。图片、语音、视频和文件按附件的扩展名识别。

发送者 ID 和文档开头"我"的 ID 相同的消息就是你发的；程序不从名字或称呼猜谁是你。

语音如果要转写，需要一个语音转写接口（OpenAI 兼容的 `/audio/transcriptions`）。转写结果保存在归档里语音文件旁边的同名 `.txt` 中，每条语音只转写一次；这是程序唯一会写进归档目录的东西。不需要时关闭"语音转写"环节即可。

## 外部 Agent

在 设置 › 接口与模型 › 外部 Agent 中勾选的文字环节（扫读、精读、查漏等）不经接口调用，改由你自己的 AI Agent 完成，用它的额度。Agent 需要能读写本机文件、运行命令。

- 估算或生成时，程序把这些环节要做的每一件事写成一个任务文件，放进交接文件夹（默认是输出目录下的 `外部处理\`，每个环节一个子文件夹）。
- 任务写出后，月报页该月份的"运行"里（专题在专题页）出现提示词生成器：勾选要交给同一个 Agent 的环节，复制提示词发给它；再换一组勾选，发给下一个 Agent。每个 Agent 发一次即可，什么时候发都可以。提示词只提到它负责的那些文件夹，Agent 碰不到归档和月报。
- 提示词里有一条检查命令，Agent 用它自己检查结果：不合格的会写明原因让它重做，都合格后它会等一会儿，有下一批任务就接着做，没有了才告诉它可以结束。你不需要在程序和 Agent 之间来回传话。
- 要用到 Agent 的结果而还没交回时，这个月停下来等（队列里别的月份照常进行）；结果交齐后自动继续，窗口开着就行。
- 收回结果时按"抽查比例"随机挑一部分，让该环节的模型再做一遍来对比，外部结果漏掉要点的改用模型的结果。所以交给外部的环节也要选好模型；不想等时也可以"改用模型做完"。
- 看图和语音转写不能交出去。

## 其他说明

- 流程：取数（含语音转写）→ 精读和扫读 → 查漏 → 结论卡复核 → 看图 → @我 → 成稿。月报附录里有每个环节的调用次数和 token 用量。
- 中断或停止后再次生成会从断点继续，已经得到的回答不会重新调用。只改某个环节的提示词或模型，只有那个环节重新调用。
- 失败与兜底：每次调用最多试 3 次；仍失败时，依次改用 设置 › 接口与模型 › 环节分配 中的兜底一、兜底二。整个环节结束后还有失败的调用，等 1 分钟、3 分钟各再试一轮。
- 预算上限在每次调用之前检查，正在进行的调用（最多等于并发数）仍会完成，所以实际用量可能略超上限。
- 数据源有变化：月报生成之后，归档里这个月的消息数变了，总览和月报上会标出来。点开可以看到变了多少、出在哪些会话，然后选择重新生成，或者保留现有月报。
- 用量只算现在保留着的这一版月报：重新生成后，不再用到的旧回答和失败的调用不再计入；删除月报或专题后，它的用量也不再显示。
- 月报里的 `[#编号]` 链接是相对路径，指向归档里的那条消息。月报和归档要保持相对位置，移动月报目录后链接会失效。
- 阅读与写作的要求在 [spec/阅读与判断准则.md](spec/阅读与判断准则.md) 和 `prompts/` 中。

## 用户数据的位置

| 位置 | 内容 |
| --- | --- |
| `%APPDATA%\ChatMonthly\`（绿色版：程序旁边的 `配置\`） | 设置、接口与模型、读取范围、任务记录、界面日志 |
| 输出目录（默认 `%USERPROFILE%\聊天记录月报\`） | 每月一个目录：月报、缓存、调用记录；`语音转写\`；`外部处理\`（交给外部 Agent 的任务和结果，位置可以在设置中改） |

## 命令行

界面做的每件事也可以用命令行完成，两者共用同一份配置。程序目录里有 `mr.exe`：

```powershell
& "$env:LOCALAPPDATA\Programs\ChatMonthly\mr.exe" plan 2026-10      # 估算：只取数和分块，不调用模型
& "$env:LOCALAPPDATA\Programs\ChatMonthly\mr.exe" run 2026-10       # 生成；中断后再次运行从断点继续
```

| 命令 | 作用 |
| --- | --- |
| `plan <月份>` | 估算，不调用模型 |
| `run <月份> [--budget-tokens N] [--api-only]` | 生成；`--budget-tokens` 是本次的上限（0 表示不设），`--api-only` 让交给外部 Agent 的环节这次改由模型完成 |
| `status <月份>` | 查看状态 |
| `check <交接文件夹>… [--wait [分钟]]` | 给外部 Agent 用：检查结果文件，不改任何文件 |
| `asr --from <月份> --to <月份>` | 只转写语音 |
| `chats [<月份>] [--find 关键词]` | 本月有消息的会话，以及它们读不读、为什么 |
| `select show｜exclude｜include｜clear｜skip-category｜read-category …` | 修改读取范围 |

## 从源码运行与打包

需要 Python 3.11 以上。

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe -m mr.app                                # 打开窗口
.\.venv\Scripts\python.exe -m mr plan 2026-10                       # 命令行，命令同上
.\.venv\Scripts\python.exe -m unittest discover -s tests            # 测试：只用自带的样例，不读真实归档，不调用模型
```

开发时可以只启动本机服务，在浏览器中打开界面：`python -m mr.app --serve --port 8765`。

生成发布文件需要再装 Inno Setup 6（`winget install JRSoftware.InnoSetup`），然后运行 `pwsh tools\build.ps1`，得到 `dist\` 下的安装版和绿色版，版本号取自 `src\mr\__init__.py`。
